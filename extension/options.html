Résumé d'article

Choisis le fournisseur utilisé pour résumer, et enregistre sa clé API.

Les clés sont stockées dans chrome.storage.local, sur cette machine uniquement. Elles ne sont jamais écrites dans le code du projet et ne sont envoyées qu'au fournisseur sélectionné.

Ce stockage n'est pas chiffré : toute personne ayant accès à ce profil Chrome peut le lire. Configure un plafond de dépense chez ton fournisseur.
